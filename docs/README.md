# docs

Just three documents in here, in roughly the order most people want them:

- [USER_GUIDE.md](USER_GUIDE.md) - install, run, troubleshoot. Start here if you just want to use the thing.

The root [README](../README.md) covers the rest (modes, config, the `-insecure` caveat).
